# Sky catalog attribution

`sky_catalog.v1.json` and `sky_stars_deep.v1.json` are derived data generated by
`scripts/build_sky_catalog.py` from the sources below. Because they embed data
from CC BY-SA 4.0 sources, **the two generated files and the hand-reviewed
crosswalk CSVs in this directory are licensed CC BY-SA 4.0** (`CC-BY-SA-4.0.txt`).
This licence covers these data files only; it does not apply to the repository's code.

Changes made to the source data: positions converted to J2000 decimal degrees and
rounded; Caldwell and Messier entries merged into one record format with a closed
`object_type` vocabulary; common names curated (citation residue removed,
multi-name cells split into a name plus aliases, typographic accents normalised);
two Caldwell positions overridden (C99, C100 — see `caldwell_crosswalk.csv`);
one corrupt Bayer token patched (`star_patches.csv`); stars filtered by magnitude.
